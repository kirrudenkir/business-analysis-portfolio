# Доработки прототипа Переделкино

Прототип подготовлен в рамках дипломного учебного проекта на основе предоставленного учебного интерфейса. Моя работа — проработка изменений пользовательских сценариев; исходное визуальное оформление магазина не является моей разработкой.

[Открыть доработанный экран завершения заказа в Figma](https://www.figma.com/design/qWZB3Hgii4qJGmF0WXL4R8/?node-id=23-3975) · [Вернуться к проекту](../README.md)

## Проработанные изменения

| Область | Требования к изменению |
| --- | --- |
| Корзина | Изменение количества, удаление отдельной позиции и отображение итоговой суммы |
| Контактные данные | Проверка обязательных полей и сообщения об ошибках |
| Доставка | Информирование об условиях доставки и самовывозе до подтверждения заказа |
| Промокоды | Ввод и проверка промокода, применение скидки, пересчёт суммы |
| Онлайн-оплата | Понятный сценарий при недоступности внешнего сервиса |
| Завершение заказа | Отображение номера, копирование и отправка номера по SMS |

На связанном экране завершения заказа показаны действия «Скопировать номер заказа» и «Отправить номер заказа в SMS». Остальные сценарии описаны в [документе с требованиями](requirements.md).

Полный учебный шаблон и инструкции к заданию в репозитории не размещаются. Ссылка ведёт на доработанный макет в Figma; для доступа могут действовать настройки самого файла.
