# Клиентский путь Переделкино

Текстовая версия авторской CJM из дипломного проекта. В карте восемь этапов: от возникновения потребности до повторной покупки. Эмоции приведены как оценка автора карты.

[Открыть оригинальную CJM в Miro](https://miro.com/app/board/uXjVHksdoHw=/?share_link_id=37155882741) · [Вернуться к проекту](../README.md)

## 1. Осознание потребности

| Элемент карты | Описание |
| --- | --- |
| Цель | Найти магазин с подходящими товарами для ремонта и дома |
| Действия | Осознаёт потребность в покупке товара, ищет подходящий магазин и переходит на сайт «Переделкино» |
| Точки контакта | Поисковик (Яндекс, Гугл, и тд), где есть ссылка на сайт |
| Эмоции | 😐 |
| Барьеры | Низкая популярность сайта и отсутствие данных о каналах привлечения клиентов не позволяют понять, как пользователи находят магазин и где могут возникать потери потенциальных покупателей |

## 2. Главная страница

| Элемент карты | Описание |
| --- | --- |
| Цель | Начать поиск товара и ознакомиться с возможностями магазина |
| Действия | Заходит на сайт |
| Точки контакта | Главная страница |
| Эмоции | 😐 |
| Барьеры | 1. Корзина расположена непривычно низко и может быть недостаточно заметна. / 2. Календарь не связан с основным сценарием покупки и занимает место на странице. / 3. Онлайн-консультант перекрывает часть контента и может мешать просмотру сайта. |

## 3. Переход в каталог

| Элемент карты | Описание |
| --- | --- |
| Цель | Перейти к ассортименту магазина и найти нужную категорию товаров. |
| Действия | Переходит в каталог и выбирает категорию товаров. |
| Точки контакта | Каталог |
| Эмоции | 😐 |
| Барьеры | Барьеров на данном этапе не выявлено |

## 4. Добавление товара в корзину

| Элемент карты | Описание |
| --- | --- |
| Цель | Добавить нужный товар в корзину |
| Действия | Добавляет нужный товар в корзину |
| Точки контакта | Каталог товаров по нужной категории |
| Эмоции | 🙂 |
| Барьеры | Клиент может добавить товар, фактическое наличие которого будет проверено сотрудником склада только после оформления заказа |

## 5. Корзина

| Элемент карты | Описание |
| --- | --- |
| Цель | Проверить выбранные товары и подготовить заказ к оформлению. |
| Действия | Просматривает состав корзины; Изменяет количество товаров или удаляет позиции,; Переходит к оформлению |
| Точки контакта | Корзина |
| Эмоции | 🙂 |
| Барьеры | 1. Кнопка удаления всех товаров визуально недостаточно выделена как опасное действие. / 2. Удаление отдельного товара из корзины неочевидно. / 3. Итоговая сумма заказа не выделена достаточно заметно. / 4. Поле для ввода промокода отсутствует. |

## 6. Оформление заказа, оплата и получение

| Элемент карты | Описание |
| --- | --- |
| Цель | Заполнить необходимые данные, выбрать способ оплаты и получения и оформить заказ |
| Действия | Указывает данные получателя и доставки; Выбирает способ оплаты — картой или наличными; Оформляет заказ; При оплате картой переходит в сервис онлайн-оплаты |
| Точки контакта | Форма оформления заказа (шаг №2,3); Сервис онлайн-оплаты |
| Эмоции | 😬 |
| Барьеры | 1. На сайте при формировании заказа могут быть указаны некорректные или несуществующие номера телефонов, из-за чего магазин не может связаться с клиентом / 2. Нет автопроверки суммы заказа, так как доставка доступна только для заказов от 1 000 ₽. При меньшей сумме клиенту сообщают, что возможен только самовывоз |

## 7. Подтверждение заказа

| Элемент карты | Описание |
| --- | --- |
| Цель | Убедиться, что заказ может быть выполнен, и согласовать его условия |
| Действия | Ожидает звонка администратора; Согласовывает содержание заказа, дату, время, наличие оплаты и адрес доставки |
| Точки контакта | Телефонный звонок администратора |
| Эмоции | 😬 |
| Барьеры | 1. Подтверждение заказа выполняется вручную администратором магазина по телефону. При недозвоне требуются повторные попытки. / После проверки склада заказ может быть отменён из-за отсутствия нужного количества товара / 2. Номер заказа отображается после оформления, но клиенту нужно самостоятельно его запомнить или сохранить для дальнейшего уточнения статуса заказа |

## 8. Оформление повторной покупки

| Элемент карты | Описание |
| --- | --- |
| Цель | Повторно приобрести необходимые товары и воспользоваться доступными предложениями магазина |
| Действия | Возвращается на сайт, выбирает товары и повторно оформляет заказ |
| Точки контакта | Сайт магазина, каталог, корзина, форма оформления заказа |
| Эмоции | 🤯 |
| Барьеры | На сайте размещена информация о промокодах, однако применить их при оформлении онлайн-заказа нельзя. Из-за этого клиент не может воспользоваться предложенной выгодой при повторной покупке |
