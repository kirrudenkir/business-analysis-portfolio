# Портфолио бизнес-аналитика

**Кирилл Руденский**

В портфолио представлены проекты по обследованию бизнес-процессов, разработке требований и проектированию изменений. Для каждого кейса указаны контекст, выполненная работа и подготовленные материалы. Целевые показатели учебных решений приведены как планируемый эффект.

## Проекты

| Проект | Задача | Методы и инструменты | Статус материалов |
| --- | --- | --- | --- |
| [Переделкино](projects/peredelkino/README.md) | Обследовать оформление и обработку онлайн-заказов и разработать требования к доработке сайта | BPMN, CJM, User Stories, Use Case, диаграммы классов и объектов, diagrams.net, Miro, Figma | Опубликованы отчёт, требования, схемы и описание доработок прототипа |
| Оптимизация обработки заказов | Проработать изменение процесса и взаимодействие Bitrix24 с 1С:УТ | AS IS / TO BE, требования, MVP, тест-кейсы, расчёт ROI | Материалы готовятся к оформлению |

## Как смотреть портфолио

Начните с README интересующего проекта. В нём описаны исходная проблема, задачи аналитика, предложенное решение, результаты работы и порядок изучения материалов.

## Состав

В `projects/peredelkino/` находятся описание дипломного проекта и две папки: `01-discovery/` с материалами обследования и `02-solution/` с требованиями и моделями решения. Документы доступны для чтения на GitHub и скачивания в исходном формате. Отдельный учебный проект по оптимизации обработки заказов будет добавлен после подготовки его материалов.

Здесь публикуются авторские результаты работы. Учебные задания, теория, квизы, исходные датасеты и замечания ревьюера в состав портфолио не входят.
